# c-kurs

## Repository Contents

This repository contains various examples and solutions for C and C++ programming. Below is a detailed description of the repository contents, including the purpose of each directory and example.

### Beispiele Directory

The `Beispiele` directory contains multiple subdirectories with different C programming examples. Each subdirectory focuses on a specific topic or concept in C programming. Here are some of the subdirectories:

- `Ablaufstrukturen`: Examples of control structures such as if-else, switch, and loops.
- `Array-Uebergabe`: Examples of passing arrays to functions.
- `Array`: Examples of using arrays in C.
- `ArraymitPointern`: Examples of using arrays with pointers.
- `ArrayofChar`: Examples of using arrays of characters (strings).
- `Baum`: Examples of binary tree structures.
- `Beispiel_Git`: Examples related to using Git with C projects.
- `Bitfeld`: Examples of using bit fields in structures.
- `Blöcke_Sichtbarkeit_Variablen`: Examples of variable scope and blocks.
- `Break`: Examples of using the break statement.
- `Continue`: Examples of using the continue statement.
- `Datentypen`: Examples of different data types in C.
- `EigeneHeader-Module`: Examples of creating and using custom header files and modules.
- `Ein-Ausgabe`: Examples of input and output operations.
- `Einfach_Verkettete_Liste_Löschen`: Examples of deleting nodes in a singly linked list.
- `Einfach_Verkettete_Liste`: Examples of singly linked lists.
- `Extern`: Examples of using the extern keyword.
- `FileRead_Format`: Examples of reading formatted data from files.
- `FileRead`: Examples of reading data from files.
- `FileReadEOF`: Examples of reading data from files until EOF.
- `FileWrite_Printf`: Examples of writing data to files using printf.
- `FileWrite_Vprintf`: Examples of writing data to files using vprintf.
- `ForwardDeclaration`: Examples of forward declarations.
- `Funktion_Simpel`: Simple function examples.
- `Funktionen_Overview`: Overview of functions in C.
- `Globale_Lokale_Variable_Funktion`: Examples of global and local variables in functions.
- `HelloWorld`: Hello World example.
- `Iterationen`: Examples of iteration (loops).
- `Komplexe-Datentypen`: Examples of complex data types.
- `Konstanten`: Examples of using constants.
- `Literals`: Examples of using literals.
- `Malloc`: Examples of dynamic memory allocation using malloc.
- `MemoryLeak`: Examples of memory leaks.
- `Operatoren`: Examples of using operators.
- `ParameterReferenzalsPointer`: Examples of passing parameters by reference using pointers.
- `Pointerarray`: Examples of arrays of pointers.
- `PointeraufPointer`: Examples of pointers to pointers.
- `QuickSort`: Examples of the QuickSort algorithm.
- `Rekursiv`: Examples of recursive functions.
- `Selection-Sort`: Examples of the Selection Sort algorithm.
- `Speicherklasse_Auto`: Examples of the auto storage class.
- `Speicherklasse_register`: Examples of the register storage class.
- `Speicherklasse_static`: Examples of the static storage class.
- `StringCopy`: Examples of copying strings.
- `Stringvergleich`: Examples of comparing strings.
- `Struct`: Examples of using structures.
- `TimeStamp`: Examples of using timestamps.
- `Typkonversion`: Examples of type conversion.
- `Vorrang_Assoziativitaet`: Examples of operator precedence and associativity.
